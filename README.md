# Инструкция по локальному запуску проекта

Предварительные требования

Убедитесь, что у вас установлены:

Java JDK (рекомендуется версия 17 или 21 — проверь pom.xml).

Maven (или используйте встроенный mvnw).

Node.js (версия 18+ или 20+, рекомендую LTS) и npm.

СУБД (PostgreSQL / MySQL / MongoDB — укажи свою).

## 1. Настройка базы данных


Установите и запустите вашу СУБД.

Создайте пустую базу данных (например, friend_finder_db).

Перейдите в папку database/:

Если в seeds/ лежат SQL-скрипты, выполните их для создания таблиц и наполнения тестовыми данными.

Если в diagrams/ есть ER-диаграмма, можете свериться с ней.

## 2. Запуск Backend (Spring Boot)
Перейдите в директорию бэкенда:

bash
cd demo/backend
Проверьте настройки подключения к БД в файле src/main/resources/application.properties (или .yml). Укажите свои логин/пароль от базы.

Запустите приложение. Используйте Maven Wrapper, чтобы не зависеть от глобальной установки Maven:

Windows:

cmd
mvnw.cmd spring-boot:run
macOS / Linux:

bash
./mvnw spring-boot:run
Альтернатива: Откройте папку backend в IntelliJ IDEA и запустите главный класс приложения (с аннотацией @SpringBootApplication).

Бэкенд запустится (обычно на http://localhost:8080).

## 3. Запуск Frontend (Vue + Vite)
Откройте новый терминал и перейдите в директорию фронтенда:

bash
cd demo/frontend
Установите зависимости:

bash
npm install
Запустите dev-сервер:

bash
npm run dev
В терминале появится ссылка (обычно http://localhost:5173). Откройте её в браузере.


## 4. Связка (если нужно)
Если фронтенд не может достучаться до бэкенда:

Проверь файл vite.config.js на наличие прокси-сервера (proxy) для API-запросов.

Или проверь файл .env (если он есть), где может быть указан базовый URL бэкенда.
